# Serial-Robotics

This project focuses on designing, manufacturing, and programming an autonomous robotic manipulator. The system must successfully complete challenges: The Tower (stacking cubes rapidly for maximum height), The Shape Sorter (precisely orienting geometric shapes into matching slots), and The Tower VS (a competitive turn-based duel).
